# Session summary — feature engineering, model sweep, and the direction problem

This session added two new price-derived feature families (drawdown/downside-risk and momentum-quality, `experiments/exp_11_downside.py` / `exp_12_temporal.py`) plus an ETF-composition family pulled fresh from yfinance (`experiments/fetch_composition.py`, `exp_13_composition.py`), bringing the design matrix to 74 trailing price/volume features. Five model families were trained and GPU-parallelized on this matrix via `run_models.py`: CatBoost, XGBoost, LightGBM, logistic regression, and a from-scratch 2-layer LSTM over raw 20-day daily sequences. XGBoost won the sweep (macro F1 0.502, rank IC 0.026 on the 2026 holdout), and a 6-year walk-forward (2021–2026) confirmed the ranking edge is real but regime-dependent — every model went flat or negative in 2022. A training-window sweep found recency beats volume: a rolling 1-year training window beat the full 9-year history on every metric, and a 4-year window that included the poisoned 2022 data was actively harmful.

The recurring, unresolved problem is direction: every multiclass model confuses "underperform" and "outperform" with each other almost as often as it gets them right (30–40% cross-confusion), because the models are good at detecting *extremeness* but not *which way* a fund will move. A two-stage ensemble (extreme-vs-neutral gate, then top-vs-bottom direction, in `experiments/model_binary_tails.py` and later scripts) roughly halved the flip rate and doubled rank IC over the plain multiclass model. Further attempts to fix it — Bayes-optimal cost-sensitive decisions (`cost_sensitive_analysis.py`), confidence-gated selectivity sweeps (`selectivity_sweep.py`), direction-specific hyperparameter tuning (`hp_tune_direction.py`), a 2-week (10-day) horizon instead of 5-day (`horizon_2week.py`, `combined_best.py`), and a training-threshold sweep for "extreme" (`fix_flip_hard.py`) — converged on the same ceiling: **~55-56% direction accuracy on genuinely extreme funds**, using price/volume-derived features alone. Raising the decision confidence threshold further doesn't improve accuracy, it just makes the model abstain (predict "neutral") on almost everything, which mechanically shrinks the flip-rate number without adding real skill.

The honest conclusion, per `experiments/final_matrices.py`: short-horizon (5–10 day) peer-relative direction for ETFs is close to the noise floor of what daily OHLCV data can support, and no amount of re-tuning the existing feature set is likely to move that ceiling much further. All model artifacts, per-config metrics (JSON/CSV), and confusion matrices from this session are saved under `experiments/results/`. Two directions are open for a future session: (1) new non-price data sources (fund flows, holdings turnover, fundamentals) that might carry direction signal price history doesn't have, and (2) deep learning / reinforcement learning architectures better suited to the cross-sectional, sequential structure of this problem — research on that is the next task.
